# so_long - 42 Warsaw

## Introduction
Welcome to the **so_long** repository! This project is an implementation of a simple 2D game written in C, developed as part of the 42 coding school curriculum. The game challenges you to navigate through a maze, collect items and reach the exit.

## Project Overview
**so_long** is a small-scale game developed using the C programming language. The main objectives of the project are to enhance your understanding of the C language, graphics handling, and game mechanics implementation.

### Features
- **2D Maze Navigation**: Navigate through a maze and find your way to the exit.
- **Item Collection**: Collect items scattered throughout the maze.
- **Graphics Rendering**: Simple yet effective graphics rendering using the MLX library.

## Getting Started
### Prerequisites
To build and run this project, you need to have the following installed on your system:
- GCC (GNU Compiler Collection)
- Make

### Installation
1. Clone the repository:
    ```sh
    git clone https://github.com/Grabarz01/so_long.git
    cd so_long
    ```
2. Build the project using Make:
    ```sh
    make
    ```

## Usage
1. Run the game:
    ```sh
    ./so_long <path_to_map_file>
    ```
2. Use the arrow keys to navigate your character through the maze.
3. Collect all the items and reach the exit to win the game.

### Example
To run the game with a sample map file:
```sh
./so_long maps/sample_map.ber
```
